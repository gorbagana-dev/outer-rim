Lucide icon wrapper (2px stroke, currentColor) — use for every glyph in Gorbagana UI; never emoji or hand-drawn SVG.

```jsx
<Icon name="trash-2" size={20} />
<Icon name="zap" color="var(--acid-500)" glow />
```

Requires `<script src="https://unpkg.com/lucide@0.475.0/dist/umd/lucide.min.js">` on the page. Falls back to a dashed box if the lib is missing. Preferred glyphs: trash-2, recycle, zap, flame, fuel, biohazard, skull, crown, sparkles, wallet, arrow-right, external-link, copy, check, x, chevron-down, search, menu.
