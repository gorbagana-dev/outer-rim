# Quality checks and proposed generation tests

## Before rendering

Confirm the selected character/body family is supported by inspected references. State internally which traits are invariant and which scene/style elements may change. Do not let another character's crown, eyes or prop leak into a named identity. Remove marketplace badges, prices and controls from the intended brief, not by pretending hidden source pixels are known. Check exact quote, attribution and ticker strings. Verify factual claims separately when needed. Use a real target for editing.

## After rendering, where inspection is available

Check identity, body architecture, eyes/mouth, headwear, hand/prop consistency, text spelling, aspect ratio and unwanted interface artifacts. Do not claim a pixel-exact edit without comparison. Respect the image tool's final-output requirements rather than adding unnecessary commentary.

Compare the rendered face against the chosen collection crop: correct fur and bin colors do not compensate for incorrect eye geometry. For flat black/gold eyes, reject round 3D bead-eye substitutions. In topical satire, check that the headline communicates the actual subject or pun directly. When the user approves a scene but corrects eyes or headline copy, keep that correction local; approval does not make the generated image a new source of canonical anatomy.

## Proposed acceptance prompts — not executed during pack assembly

| Prompt | Expected behavior |
|---|---|
| Make a Gorbagio gas-station attendant selling $GOR fuel. | Read/select a few references, create a new scene, no clovers, marketplace cards or unverified network claims. |
| Make #4051 a noir detective, preserving its body and glasses. | Use the mattress-like #4051 reference, retain quilted slab/glasses; do not replace it with a furry bin. |
| Make #2702 supervise a scrap-built server room. | Preserve its teal/green body and recognizable face; allow requested scene changes, no arbitrary crown/boxing gloves. |
| Create a council scene with three different kinds of Gorbagio. | Three coherent architectures, not one hybrid combining every body family. |
| Keep this exact quote card, only change attribution to Gorbage S. Gorroughs. | Require the actual card image; preserve quote and other elements; do not recreate an unseen earlier image. |
| Put the official GOR logo on a poster. | Obtain a clean supplied/verified logo, not a clover, tiny sticker or cereal-box label. |
| Give me five literary Gorbagio concepts, no images. | Return concepts only; do not call an image tool. |

The compact bundle's file counts, image decoding, unchanged crop dimensions, current JPEG hashes, active reference paths and YAML structure were checked during assembly. Historical source hashes were checked against the earlier v2 archive, which is not bundled with this edition. These checks do not test installation, runtime image-input delivery or generated-image fidelity.
