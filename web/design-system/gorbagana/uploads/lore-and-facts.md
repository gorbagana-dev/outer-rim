## Dynamic facts: verify before asserting

Do not hard-code or invent any of these into factual marketing copy:

- current mainnet/testnet/devnet status;
- current bridge status or bridge mechanics;
- current number of validators;
- current finality/latency measurements;
- current throughput;
- current wallet support;
- floor price, market cap, volume, price, holder count;
- live dapps or ecosystem rankings;
- airdrop eligibility or NFT utility;
- token distribution, treasury balances, or roadmap dates.

When the user needs a factual claim rather than a pure meme, verify against current primary sources immediately before using it. Official docs can lag the official site, so treat date/context as material when sources conflict.

## Canonical copy versus meme copy

Distinguish:

- **factual copy:** “$GOR is the native gas token” -> verify if current context requires legal/technical precision;
- **brand/lore copy:** “THE CHAIN IS TRASH. THAT'S THE POINT.” -> stylistic and does not need to be presented as a technical claim;
- **obvious parody:** “Trash Council Monetary Authority” -> fictional unless the user explicitly means the real Trash Council.

Do not accidentally turn a fictional meme institution into an asserted real organization.

## Contract-address discipline

If a visual needs the real `$GOR` contract address, use the exact canonical string from a current official source. If exactness is unnecessary, prefer the ticker `$GOR` and avoid tiny unreadable addresses in the image.
